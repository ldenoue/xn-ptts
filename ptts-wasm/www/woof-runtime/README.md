# Underdog Woof browser runtime

`woof.js` and `decoder-0TmyPaji.js` are the browser runtime served by
<https://underdog.ai/woof>, retrieved on November 7, 2026. They are kept in
their generated form so the browser demo can run the upstream model exactly.

Underdog Woof is restricted to non-commercial use unless separately licensed.
The upstream `LICENSE` and `NOTICE` are included unchanged. The xn-ptts project
license does not replace or relax those terms.

The model weights are not stored in this Git repository. They are mirrored,
unchanged and with provenance, at
<https://huggingface.co/ldenoue/Underdog-Woof-WebGPU>.

The integration wrapper is `../woof_worker.js`.
